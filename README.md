
# Sistema de Gestión de Inventarios

## Descripción
Proyecto final desarrollado en Java que permite administrar diferentes tipos de productos utilizando programación orientada a objetos.

## Tipos de productos
- Electrónicos
- Alimentos
- Ropa

## Funcionalidades
- Registrar productos.
- Mostrar el inventario.
- Buscar productos por código.
- Actualizar existencias.
- Eliminar productos.

## Conceptos aplicados
- Clases abstractas.
- Interfaces.
- Herencia.
- Polimorfismo.
- Encapsulamiento.

## Tecnologías utilizadas
- Java
- IntelliJ IDEA
- Git
- GitHub

## Estructura del proyecto
- Inventariable.java
- Producto.java
- Electronico.java
- Alimento.java
- Ropa.java
- Inventario.java
- Main.java

## Ejecución
Abrir el proyecto en IntelliJ IDEA y ejecutar la clase Main.
